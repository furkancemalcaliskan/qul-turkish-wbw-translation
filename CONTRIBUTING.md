# Contribution policy

External contributions are currently closed. Please do not open pull requests,
translation proposals or unsolicited review requests. They will not be reviewed
or merged while this policy is in effect. Maintenance is limited to the repository
owner; this public repository exists to make the correction history and release
artifacts inspectable.

The planned contribution of this dataset to Tarteel AI's Quranic Universal Library
is a separate maintainer-led process documented in [QUL_CONTRIBUTION.md](QUL_CONTRIBUTION.md).
It does not mean that this repository accepts external contributions or that QUL
has approved these changes.

Do not modify the original files under `resources/`. Their SHA-256 hashes are
fixed in [reports/resource-integrity.json](reports/resource-integrity.json).
Any future reopening of contributions will be announced here with an explicit
review process. No dataset licence or redistribution permission is granted by
this contribution policy.
